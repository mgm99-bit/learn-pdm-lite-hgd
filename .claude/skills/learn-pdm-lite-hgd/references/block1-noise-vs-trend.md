## EXPLAIN

### 1. 용어 (5일차 덱 p12·p14·p19)

| 용어 | 뜻 |
|---|---|
| 이상 패턴 (anomaly) | 평소와 크게 다른 값이나 흐름 |
| 평상 범위 | 평균 ± 2표준편차. 이 범위를 벗어난 값을 "이상 후보"로 표시한다. **설비별로 따로** 계산한다 |
| 노이즈 | 한 번 튀고 곧 정상으로 돌아오는 일시적 값. 측정 오류·순간 외란일 수 있다. 한 점의 이상치는 정비 신호가 아니다 |
| 추세 | 임계선을 향해 꾸준히 오르는 흐름. 이 상승의 **시작점**이 진짜 정비 신호이고, "고장 전 계획 정비"의 기준점이 된다 |

### 2. 왜 평상 범위에 흐름까지 보는가

| 기준 | 평균만 본다 | 평균 ± 2σ만 본다 | 평균 ± 2σ + 흐름을 본다 |
|---|---|---|---|
| 얼마나 벗어났나 | 판단할 수 없다 | 이상 후보를 객관적으로 표시 | 이상 후보를 객관적으로 표시 |
| 노이즈와 추세 | 구분 못 함 | 한 점과 흐름을 똑같이 '이상'으로 본다 | 한 번 튐은 노이즈, 꾸준한 상승은 신호로 가른다 |
| 정비 시점 | — | 임계선을 넘은 뒤에야 안다 | 상승이 시작된 시점에 계획 정비를 잡는다 |

### 3. 케이스 (5일차 덱 p8)

한 제조사가 설비 진동 데이터를 상시 감시하다가 평소와 다른 미세한 진동 증가를 포착해 고장 직전 부품을 교체했다. 그대로 뒀다면 라인 정지·부품 파손으로 며칠치 생산이 날아갈 상황이었다. 작은 신호를 데이터로 읽으면 큰 사고를 작은 정비로 막는다.

## EXECUTE

아래 프롬프트를 붙여 넣으라고 안내한다. 1~3번은 원본 덱 ③ 전처리·④ 분석 1의 입력 프롬프트 그대로다.

```
pdm-lite 폴더의 sensor_50_virtual.csv 로 아래를 해 줘.
1. 센서 데이터를 [시간 / 진동 / 온도 / 압력] 표로 정리하고, 각 변수의 평균·표준편차와 평상 범위(평균 ± 2표준편차)를 계산해줘. 평균·표준편차는 설비A와 설비B를 따로 계산해줘.
2. 범위를 벗어난 값은 "이상 후보"로 표시해줘.
3. 이상 후보가 일시적 노이즈인지 추세적 상승인지 구분하고, 추세적 상승이 시작된 시점을 "정비 필요 시점"으로 표시해줘.
4. 결과를 anomaly_table.csv 로 저장해 줘(열: 설비, 시간, 변수, 값, 평상범위 하한, 평상범위 상한, 판정).
5. index.html 에 그래프 한 장만 만들어 줘: 가로축 시간, 세로축 진동(mm/s), 설비A·설비B 두 선, 설비별 평상범위 상한(평균+2σ) 점선, 이상 후보 점 표시, 정비 필요 시점 표시. 제목 아래에 "가상 데이터(실습용)"라고 적고, 외부 라이브러리 없이 파일 하나로 열리게 해 줘. 휴대폰 폭에서도 보이게 해 줘.
6. 원본 CSV는 고치지 마. 다 되면 index.html 을 열어서 보여 줘.
```

### 확인할 것 (Phase B)

- `~/pdm-lite/anomaly_table.csv`를 직접 읽어 이상 후보를 확인한다.
  - 설비A 진동 평상범위 상한 ≈ 2.08 · 이상 후보는 12:40 3.5 한 점 → 노이즈
  - 설비B 진동 평상범위 상한 ≈ 2.07 · 이상 후보는 15:40 2.2 · 16:00 2.9 → 추세
  - 설비B 온도 이상 후보 16:00 65.1
  - 설비A 온도·압력, 설비B 압력은 이상 후보 없음
  - 설비B 정비 필요 시점 = 15:00 (진동 1.0 → 1.3으로 연속 상승이 시작된 시점)
  - 상한은 모표준편차 기준이다. 표본표준편차(pandas 기본)로 계산했으면 2.10 · 2.08로 나오고, 이것도 맞다. 이상 후보는 같다.
- `index.html`이 있고 그래프가 한 장인지, "가상 데이터(실습용)" 표기가 있는지 본다.
- 판정이 다르면(예: 설비A 3.5를 '추세'로) 원본 덱 p29의 자가 점검 프롬프트를 준다.

```
이 분석에서 일시적 노이즈를 추세로 잘못 본 부분이 있는지 찾아줘.
```

평균·표준편차가 다르면 아래 후속 프롬프트를 준다.

```
평균·표준편차를 설비A·설비B 따로 계산했는지, 50건을 한꺼번에 계산하지 않았는지 확인하고 원인을 알려 줘.
```

## QUIZ

```json
AskUserQuestion({
  "questions": [{
    "question": "같은 날 두 설비의 진동(mm/s)이 보고됐다. 설비 A: 1.0 → 1.1 → 0.9 → 3.5 → 1.0, 설비 B: 1.0 → 1.3 → 1.7 → 2.2 → 2.9. 두 설비 모두 평상 범위 상한은 약 2.1이다. 이번 주 계획 정비에 한 대만 넣을 수 있다면 어떻게 판단해야 할까?",
    "header": "Quiz 1",
    "options": [
      {"label": "설비 A", "description": "최고값 3.5가 B의 2.9보다 높으니 더 위험하다"},
      {"label": "설비 B", "description": "임계선을 향해 꾸준히 오르는 추세다. A의 3.5는 한 번 튀고 돌아온 노이즈다"},
      {"label": "둘 다 같다", "description": "둘 다 상한을 넘은 값이 있으니 똑같이 이상이다"},
      {"label": "다음 주까지 관찰", "description": "B는 아직 상한을 넘은 점이 두 개뿐이니 더 지켜본다"}
    ],
    "multiSelect": false
  }]
})
```

정답: 2번. ① 설비 B는 1.3부터 매번 오르며 임계선을 넘어선 추세적 상승이고, 이 상승의 시작점이 진짜 정비 신호다. ② 설비 A를 고르는 것은 원본 모범답안의 감점 사례 "한 번 높았으니 위험"으로, 노이즈와 추세를 혼동한 것이다. 3.5는 바로 1.0으로 돌아온 일시적 값이라 한 점의 이상치는 정비 신호가 아니다. "둘 다 같다"는 평상 범위만 보고 흐름을 보지 않은 판단이고, "다음 주까지 관찰"은 추세의 시작점을 잡아 고장 전에 계획 정비한다는 예지보전의 목적을 놓친다. ③ 현장에서는 이상 후보가 나오면 먼저 "한 점인가, 흐름인가"를 보고, 흐름이면 시작 시점을 기준으로 정비를 계획한다.
